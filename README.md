# Atividade 2 - RastreiaJá

Página estática de rastreio feita com HTML5 semântico e CSS externo. Para visualizar, abra `index.html` no navegador.

## Arquivos

- `index.html`: página refatorada com os dados de exemplo do enunciado.
- `estilo.css`: apresentação separada do HTML, incluindo ajuste para telas pequenas.
- `diagnostico.md`: problemas do HTML legado e soluções propostas.

Os links de navegação são locais: **Nova consulta** recarrega a página de exemplo e **Ajuda** vai para a seção de ajuda. Uma consulta real exigiria dados de um serviço de rastreio, que não faz parte desta atividade.
